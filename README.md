# Habit Tracker for Flipper Zero

A habit tracker app for the [Flipper Zero](https://flipperzero.one/). Add habits,
log them daily or several times a day, and see a GitHub-style grid showing how
many days across the past year each habit was completed.

> **Disclaimer:** The code in this repository was generated by an AI
> (Anthropic's Claude). It has been compiled against the official Flipper Zero
> SDK, but it has not been thoroughly reviewed or tested. Use it at your own
> risk.

## Features

- **Habit list** showing today's progress for each habit, e.g. `[x] Read 1/1`
  or `[ ] Water 3/8`.
- **Intervals:** daily, or 2–12 times a day.
- **Year grid:** the last 53 weeks per habit, one column per week (Sunday to
  Saturday). The year is split into two stacked rows to fit the 128×64 screen.
  - `·` dot: not done
  - hollow square: partly done (multi-per-day habits)
  - filled square: done
- **Header** shows the habit name (or selected date), the selected day's count
  such as `2/3`, and the number of days completed in the past 365 days, such as
  `87d`.
- **Back-filling:** move to any past day in the grid and log or undo completions.
- Up to 16 habits, each with a year of history.

## Controls

On the habit screen:

| Button      | Action                         |
|-------------|--------------------------------|
| OK          | Log one completion             |
| Hold OK     | Remove one completion          |
| Up / Down   | Previous / next day            |
| Left / Right| Previous / next week           |
| Back        | Save and return to the list    |

Use **+ Add Habit** to create a habit, and **Edit Habits** to change a habit's
interval, rename it or delete it.

## Building

The app is built with [uFBT](https://github.com/flipperdevices/flipperzero-ufbt).

```sh
python3 -m pip install --upgrade ufbt
ufbt            # build dist/flipper_habit.fap
ufbt launch     # build, install and run on a connected Flipper
```

The app then appears under **Apps → Tools → Habit Tracker**.

## Data

Habits are stored on the SD card at
`/ext/apps_data/flipper_habit/habits.dat`. They are saved when you leave a
screen and when the app exits.

"Today" comes from the Flipper's real-time clock, so make sure the date is set
correctly. Changing a habit's interval also changes how past days are shown,
since they are always compared against the current target.
